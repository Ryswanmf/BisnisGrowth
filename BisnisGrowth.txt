Buatkan aplikasi web direktori bisnis & link-in-bio bernama "BisnisGrowth"
menggunakan stack:
- Laravel 12 (PHP 8.3+)
- Blade templating (SSR — wajib untuk SEO)
- Tailwind CSS 3 via Vite
- MySQL 8
- Vite sebagai asset bundler

=== STRUKTUR DATABASE ===

Tabel: users
- id, name, email, password, role (user|admin)
- email_verified_at, remember_token, timestamps

Tabel: categories
- id, name, slug (unik), icon (emoji/string), description
- is_active (default true), order (int), timestamps

Tabel: businesses
- id, user_id (FK → users)
- name, slug (unik, SEO-friendly, index)
- tagline (varchar 160), description (text)
- category_id (FK → categories, index)
- logo (nullable), cover_image (nullable)
- phone, whatsapp, email, website
- address, city, province
- instagram, facebook, tiktok, youtube
- theme_color (default: '#7B1F2E')
- is_verified (bool default 0), is_active (bool default 1)
- view_count (int default 0), click_count (int default 0)
- meta_title (nullable), meta_description (nullable)
- timestamps

Tabel: links
- id, business_id (FK), title, url
- icon (varchar — nama icon Heroicons/string emoji)
- order (int default 0), is_active (bool default 1)
- click_count (int default 0), timestamps

Tabel: page_views
- id, business_id (FK, index)
- ip_address, user_agent, referrer
- created_at

Tambahkan index pada: businesses.slug, businesses.category_id,
businesses.is_active, page_views.business_id, page_views.created_at

=== SEO TEKNIS ===

1. Buat Blade component: resources/views/components/seo-head.blade.php
   Props: $title, $description, $canonical, $ogImage = null,
          $robots = 'index, follow', $jsonLd = null
   Isi semua meta tag + OG + Twitter Card + JSON-LD

2. Gunakan @component('components.seo-head', [...]) di setiap halaman

3. Sitemap XML (GET /sitemap.xml):
   Controller: App\Http\Controllers\SitemapController
   Isi: halaman statis + semua /{slug} bisnis aktif + /kategori/{slug}
   Format: <?xml version="1.0"?>...<urlset>...<url>...<loc>...<lastmod>
   Response header: Content-Type: application/xml

4. robots.txt (GET /robots.txt):
   User-agent: *
   Allow: /
   Disallow: /admin
   Disallow: /dashboard
   Sitemap: https://bisnisgrowth.id/sitemap.xml

5. Slug generation (saat register/simpan):
   $slug = Str::slug($nama);
   Cek unik di tabel businesses, jika sudah ada tambah -2, -3, dst.

6. Redirect klik link:
   GET /go/{linkId} → increment link.click_count → redirect($link->url)

=== STRUKTUR ROUTE (routes/web.php) ===

// Public
Route::get('/', [HomeController::class, 'index']);
Route::get('/direktori', [DirectoryController::class, 'index']);
Route::get('/kategori/{slug}', [CategoryController::class, 'show']);
Route::get('/sitemap.xml', [SitemapController::class, 'index']);
Route::get('/robots.txt', [SitemapController::class, 'robots']);
Route::get('/go/{link}', [LinkRedirectController::class, 'redirect']);
Route::get('/{slug}', [BusinessProfileController::class, 'show'])
     ->where('slug', '[a-z0-9\-]+');  // harus PALING BAWAH

// Auth
Route::middleware('guest')->group(function () {
    Route::get('/login', [AuthController::class, 'showLogin']);
    Route::post('/login', [AuthController::class, 'login']);
    Route::get('/register', [AuthController::class, 'showRegister']);
    Route::post('/register', [AuthController::class, 'register']);
});
Route::post('/logout', [AuthController::class, 'logout'])
     ->middleware('auth');

// Dashboard
Route::middleware(['auth', 'verified'])->prefix('dashboard')
     ->name('dashboard.')->group(function () {
    Route::get('/', [DashboardController::class, 'index'])->name('index');
    Route::get('/profil', [BusinessSettingController::class, 'edit'])->name('profil');
    Route::put('/profil', [BusinessSettingController::class, 'update'])->name('profil.update');
    Route::get('/links', [LinkController::class, 'index'])->name('links');
    Route::post('/links', [LinkController::class, 'store']);
    Route::put('/links/{link}', [LinkController::class, 'update']);
    Route::delete('/links/{link}', [LinkController::class, 'destroy']);
    Route::post('/links/reorder', [LinkController::class, 'reorder']);
    Route::get('/analytics', [AnalyticsController::class, 'index'])->name('analytics');
});

// Admin
Route::middleware(['auth', 'role:admin'])->prefix('admin')
     ->name('admin.')->group(function () {
    Route::get('/', [AdminDashboardController::class, 'index']);
    Route::resource('businesses', AdminBusinessController::class);
    Route::resource('categories', AdminCategoryController::class);
    Route::resource('users', AdminUserController::class);
});
